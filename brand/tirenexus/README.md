# brand/tirenexus

Sistema de identidad de TireNexus (brazo mayorista B2B).

| Archivo | Qué es |
|---|---|
| `brandbook.html` | Manual completo navegable con los mockups de todas las aplicaciones. Se publica tal cual. |
| `BRAND.md` | Fuente de verdad en texto: reglas, valores y especificaciones. |
| `tokens/tokens.json` | Design tokens (color, tipografía, forma, espaciado). |
| `tokens/tokens.css` | Los mismos tokens como custom properties, listos para sitio, portal y correo. |
| `logo/` | Lockups, reverso, apilado, monocromo, símbolo, monograma y el raster maestro. |

Vista previa local: `node serve.js` y abrir `/brand/tirenexus/brandbook.html`, o abrir el archivo
directamente en el navegador. Las tipografías (Saira, IBM Plex) se cargan desde Google Fonts.

Antes de producir cualquier pieza física, resolver todos los campos marcados **VERIFY** en `BRAND.md`.
